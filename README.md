# CineMedia Showcase

Proyecto web diseñado para presentar proyectos audiovisuales e interactivos, desarrollado como parte del curso "Desarrollo de Experiencias Multimedia para la Web".

## Objetivos del Taller
- Implementar maquetación responsiva con CSS Grid y Flexbox
- Distribuir tareas colaborativas en equipos de desarrollo
- Aplicar Buenas Prácticas de Arquitectura en Maquetación Web

## Tecnologías
- **HTML5**: Estructura semántica del contenido
- **CSS3**: Flexbox para navegación, Grid para galerías, Media Queries para responsividad
- **Git/GitHub**: Control de versiones y colaboración en equipo
